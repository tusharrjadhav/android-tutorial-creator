# Contributing

Keep the skill focused on creating learning material. Explain why an instruction improves a learner's outcome; avoid adding general coding rules unrelated to teaching.

Run `python3 -m unittest discover -s tests -v` and `python3 scripts/check_project.py` before submitting changes. Exercise changed scaffold behavior in a temporary directory. Never commit generated Android caches, credentials, or local SDK settings.

For Android examples, verify dependencies against primary documentation and record actual build/test results. Do not describe unrun checks as passing.
